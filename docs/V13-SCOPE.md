# V13 个体行为、近距离交战与实际镜头放大

按用户连续补充要求执行。保留 V12 已渲染版本；仅在独立 V13 目录继续。红方 972、蓝方 252，初始站位及素材不变。使用原生 FBX 骨骼和已有 IK 奔跑适配，保持高速冲锋与无反向击退。

审计发现：红方在 V12 已有逐人积分、独立启动和相位；蓝方也有逐人相位及周期，不能错误声称此前完全共用动画。但蓝方首轮事件受“所有人到齐之后”的统一门槛控制，启动跨度窄，首发释放集中；没有真实射程门槛。可见效果因而接近同步部署和齐射。V13 移除此全军到齐门槛，用每人到位、转向、拉弓、瞄准、释放、恢复及射程判断驱动事件。

增加蓝方部署距离至 7.5，个人部署时长及启动由稳定 ID 派生；每人有独立攻击持续时间。目标须位于 38 世界单位内，按真实目标坐标生成箭矢和伤害。射程是制作参数而非已获策划确认的数值。若目标未进入射程，射手按自身状态等待，不假装放箭。

实际摄像机在前 1.45 秒平滑从 zoom 2.55 收近至 2.95，同时沿地面移动 2 单位，视角恒定；随后固定。初始试验直接使用固定 2.95 时几乎裁掉全部前锋，已据截图纠正为缓慢连续收近，避免突然变焦和开场空镜。全程无切镜或画中画。单独的诊断视频允许跟踪放大，以验证同一小方阵中的个体状态；诊断镜头不进入正片。

真实活动占位、稳定身份、因箭矢命中触发的个体反应、持续高速推进及接触前结束为硬约束。最终观感单独记录，不把相位数量当作独立动作已经可见的充分证据。
