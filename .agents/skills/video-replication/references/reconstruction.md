# 空间、身份与连续运动

## 把可观察结构落实到显示实体

先确认对象粒度和身份匹配证据，再确定显示表达。不能由填满轮廓的采样点反推真实个体数。群体占据范围与成员密度联合检查，保留真实缺口、弧线、多段占据和局部不规则。

已有稳定成员的空间修正优先最小位移匹配。`reconstruction.stable_mask_layout(mask, previous)` 在支持掩膜内最远点采样，再用 Hungarian 将旧 ID 顺序映射到目标；不改成员数。它是显示分布，不是自动识别真实成员。

`occupation_quantiles(mask, uv)` 用横向面积 CDF 和条件纵向占据分位，将固定槽位分位映到实际支持，可保留不连续截面。它不保证不同分位落到不同像素，不保证碰撞，也不解释分裂/合并身份。窄区不足以容纳时拒绝/降为未通过，不能悄悄堆点。

需要精修时按项目加入中心、轮廓距离场、覆盖、主轴、尺寸、邻队间隔、速度、时间二阶差分等约束。最小二乘只是局部优化工具；权重/边界按观测误差和尺度设定，拟合帧与留出帧分开。`fit_path` 提供二维有界路径拟合，调用者负责留出误差与实际渲染检查，不自动优化群体所有约束。

## 不以中心插值代替成员过程

用源证据确定进入、展开、停步、转向、接触、退出和遮挡时间。对长队/非刚性形变，将成员关联到局部中心线、横截面、头中尾或可观察片段，而非始终刚体平移。固定槽位分位随时间平滑改变，避免每帧重新采样/排序造成身份跳变。

在拟合关键帧之间检查真实视频：短时加速、转角、队列前缘与邻队接触都可能被普通线性插值漏掉。只在证据允许的短 gap 内插值，长 gap 标 UNKNOWN；选择 hold 只是未知状态的表示，不能宣称原片保持不动。

轨迹绝对时间求值，使随机寻帧与顺播同版本一致；粒子/动画也不能依赖此前渲染了哪些帧。窗口携带每个稳定 ID 的终态、速度、姿态和生存状态；边界待确定时标待集成，不自行假定。

## 保护既有模块

排列主轴与单体瞄准分离，近方形/碎片 PCA 低可靠时不强制旋转。无形变证据时可用 medoid 稳定形状，但不能用它抹去原片真实展开。死亡固定位置、生存状态及攻击门禁沿用已验证控制器；死后旧烟可以继续，不能新发射。

`continuous_min_distance` 对两条帧间线性轨迹计算精确最小距离，能抓住端点都安全但中途穿越；非线性轨迹需细分或对应解析法。完整安全 DP 是历史项目方法参考，本 Skill **未提供整套 DP/导航实现**。无新增穿透不等于更像原片。

## 最终生效验证

1. 查当前帧每个成员的实际位置写入者；`resolve` 可演示显式优先级和冲突拒绝。
2. 改目标参数后比较最终 state，而不只比较输入 JSON。
3. 若被高层绝对轨迹覆盖，重建该窗口缓存并比较其哈希；不可把无变化解释成优化幅度不足。
4. 渲染连续片段与留出帧；退化候选回滚并保留失败原因。回滚可局部执行，但必须重验跨窗边界。
