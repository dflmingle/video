# 条件性方法：空间与群体演出

仅在镜头涉及多角色汇流、排队、换位、通道、接触或拥挤时阅读。单角色展示、UI演示、道具合成等任务无需引入整套人群系统。

## 先明确镜头要求，再选择运动方案

关键帧、路径编排、局部避让与完整模拟都可用；依据可见镜头及用户要求选择。若要求逐人行走、阻挡和避让，不能用整组平移冒充；若只需确定性展示，不擅自扩大成完整战斗 AI。

追踪剧情命令 → 个体目标 → 路径 → 空间/接触约束 → 状态 → 最终姿态。多个独立控制类仍可能追随同一错误公式；加 Update、随机相位或动画不会消除错误依赖。

## 同类任务优先采用的具体方案

用户在本轮经验沉淀中明确指定，后续同类镜头需要保留以下选型，不将它们抽象到失去实施依据：

1. **地面角色之间需要碰撞、阻挡和避让时，用 ORCA 作为局部速度避让方案。** 输入真实位置、身体半径、期望速度和邻居信息；再用扫掠及接触保护约束实际积分与最终显示位移。覆盖同方、异方和特殊角色，不能把只添加 Collider 或“看起来会绕开”称为碰撞完成。
2. **静态背景中的桥面，先建立贴合可走区域的 Mesh 和 MeshCollider。** 轮廓可在编辑器调整、可显示诊断覆盖层；显示 Mesh 与 MeshCollider 使用同一几何。先确认标定贴合画面，再调行军，不继续在各运动分支里各写一套桥宽/桥头坐标。
3. **用同一份桥面轮廓驱动整条空间链路。** 从它派生 ORCA 两侧障碍边、开放入口/出口、路线锚点、身体边界扫掠和整队路径检查；MeshCollider 不会自动变成 ORCA 障碍，必须显式接通数据。
4. **联动验收，不能各自通过就算完成。** 同时检查身体不出桥、角色不重叠、入口不断流、边缘不被推卡住、目标真实到位，以及原剧情阶段与结尾不变；包括攻击前踏等最终显示偏移。

适用范围是此类受地面通道约束的角色/人群演出。翻滚、抛飞、刚体堆叠等若需要真实物理应另选合适工具；ORCA 不能替代这些物理过程。新需求确实超出上述模型时，说明原因再调整方案，不机械扩用，也不无故遗忘已确认的选型。

## 用权威几何替代分散坐标

- 静态背景图不自带通行信息。按实际镜头标定可行区域与入口，提供可见、可编辑的轮廓；合适时由同一数据派生 Mesh、Collider、运动边界与路径锚点。
- 几何表示适配地形：简单凸区、凹区、弯道、多层通道不能无差别处理。路径目标、整段运动、积分结果和显示偏移都应使用一致约束。
- 若用 ORCA，可走面通常由阻挡侧边界限定，并保留合法出入口；不要把整块道路作为实心障碍封死。MeshCollider 不自动驱动自写求解器，必须明确实际数据连接。
- 检查真实身体尺寸的扫掠，不只看中心、左右分区或端点。开放口、转弯和沿岸过渡使用一致约定；硬截断后回查卡住、重叠和反向弹回，必要时沿边滑行或规划入口对齐。
- 编辑轮廓后更新派生资产与缓存，支持的 Undo/Redo 也要恢复一致。查询依赖物理时验证真实查询命中，而非只看组件。

## 连续移动与占位

- 同速要求先明确世界速度或屏幕速度；曲线路程按累计路径距离计算，不用端点弦长。自由行走、排队和接触减速分开比较。
- 密集移动时，入口供给、身体尺寸、目标与速度需一起可行。ORCA 是速度避让，不能只凭名称保证无重叠；按需求覆盖同阵营、跨阵营与特殊对象的接触。
- 特殊单位的优先级进入实际接触求解，不能只改速度偏好。推挤传递仍服从地图边界和邻居占位；记录原因，避免把所有倒退都当合法例外。
- 动画前踏、根运动、受击位移也是最终占位；同时动作需要相对扫掠，武器/特效复用修正后的位置。
- 个体离场或死亡不能让其他存活角色瞬间重排。群体边界变化可能来自成员变化，不等于同一批人后退；例如清线可由前排阵亡、后续继续推进形成。
- 区分正常等待、阻挡、未接敌、交互和到位。记录指定对象原因，不用“其他人在动”证明它正常。

## 稳定收束与事件因果

终点分配要稳定，阶段切换要可重建。先合法离开通道再绕过已到位对象；路径和碰撞使用同一身体约束。完成条件依据用户要求的真实状态，不能以人数或截止时间替代全部到位。

因果事件绑定实际参与者：动作发起者 → 有效目标 → 对应接触/命中 → 目标反馈。既定伤亡、胜负或道具结果由编排控制时，提前安排可行站位和时机；不能临时选任意发起者、远处强杀或让旁观者同步抖动。

上述方法来自固定战斗镜头中的失败链，可迁移到队列、运输、逃脱和多人展示；不代表这些题材都必须采用相同算法，也不保证地面圆形占位能覆盖模型所有视觉轮廓。
