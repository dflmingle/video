# V11 制作范围与直接验收

用户已授权直接制作完整战斗版。沿用 V10 模型、初始 1224 人布局与成员 ID；不修改 V10、RiverBattle 或 Unity 工程。

1. 固定高位俯视：在当前真实角色下试取景，首尾阵型完整，镜头全程参数一致。
2. 成员运动：收紧 V10 多层叠加的速度差，避免无伤成员追赶压团；连续积分、预测超越和占位约束继续有效，不锁固定格子，不增随机位置偏移。
3. 战斗：蓝方部署结束后错峰放箭；实际手部发射坐标、连续弹道、明确目标 ID、落点命中、单人踉跄减速和原地死亡共用事件。
4. 视觉：在最终画幅检查奔跑、箭体方向和受击可读性；不增加人数、不用额外粒子遮盖运动。
5. 编码后查看全流程抽帧及受击连续片段，交付完整 MP4、V10/V11 对照、初始与中段截图、掉队连续证据。

工程门槛：初始布局精确一致；活成员占位不重叠；阵营间距保守下界达标；无反向推进、无切镜；命中和状态一一对应；最终产物绑定当前源码哈希。艺术判断与用户认可单独记录。
