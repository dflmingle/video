## 排除导出遗漏

- 六个场景与 24 个 Prefab、72 个模型均由 Unity 原生加载检查；模型层级包含全部子网格。
- CastleExterior 场景环境 34 个 MeshRenderer，无未激活的环境 Renderer，无空 Mesh 的 MeshRenderer/SkinnedMeshRenderer。
- Building.fbx 只有两个实际子网格，分别 1178 和 690 顶点；没有另一个被隐藏的完整城门或告示牌网格。
- CastleExterior_Grp 对外唯一未解析 GUID `474bcb49853aa07438625e644c072ee6` 出现在 m_Script 字段，不能当作丢失的城堡几何。其他场景有缺少的运行脚本，不代表原工程可直接运行。
- 九个嵌套包逐项读过 pathname 和引用，未发现 .unity 场景；它们是角色/特效资源，不含已确认的完整替代城堡环境。
