## 约 3 秒可行性：只计算，尚未制作

现有并行运动实验保持：红蓝首批均在第 1 帧真实移动，重叠约 2.1833 秒，保守最小净距 4.2966，安全结束约 2.20 秒。首次释放 2.0333 秒，安全结束前没有命中。不能将视频长度直接改成 3 秒。

只读预算发现：约 1.1667 秒已经有人进入真实 34 单位射程，但仍处 ARRIVING。若角色确实支持集结中提前完成上身准备，按原约 0.199 秒拉弓和原弹道计算，乐观释放约 1.3667 秒、命中约 1.6667 秒。**这是可行性假设，不是已经发生的真实事件，也没有验证移动射击动画支持。** 优先候选是消除不必要的到位后准备等待，不改箭速、冲锋速度或起始阵位。

这只能改善火力开始时间，不能单独保证 3 秒安全。用最后 0.1 秒速度做无新战斗事件外推，在 2.8/3.0/3.2 秒维持约 4.1 净距，对应额外起始纵向间隔估计约 13.55/18.27/22.99 单位。它是模型预测，**不是已验证最小调整**；提前命中改变前锋后还需完整重模拟。当前没有擅自改正式起始位置。

场景确认后才能在隔离实验中验证提前准备/放箭的实际收益，再用真实轨迹判断能否达到约 3 秒。若仍不足，则提交最小空间调整方案供确认；不加等待、不降速度、不增加击退。
