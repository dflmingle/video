# 重要视觉事件的发现、重建与验收

仅在参考含影响理解或观感的重要视觉事件时应用。炮击、魔法、爆炸、粒子、车辆尾迹、流体、光效只是可能内容；普通视频不强加这些对象。对连续流体/尾迹可用稳定对象加活动时间窗表示，不强行拆成发射与命中。

流程：参考视频 → 事件发现 → 事件时间与空间定位 → 视觉阶段分解 → 轨迹与持续时间重建 → 素材或程序化效果映射 → 实际渲染 → 最终视频逐事件验收。

## 全片发现与证据定位

1. 核实本次参考文件、哈希、实际时长、帧率/PTS及裁切，与旧版本分开。完整扫描从开头到结束的镜头/活动窗口，后半段同等记录；密集、快速和遮挡区间加密，不能只查开场或复制前段事件。
2. 先观察局部连续画面，区分瞬时闪光、持续移动实体、线条、扩散和残留。颜色连通域、亮区变化、光流或局部跟踪用于候选；它们不自动证明事件类型、发射者、命中因果或总事件数。按实际内容选择方法，不把某一颜色/速度筛选器当通用检测器。
3. 每条记录稳定ID、源文件与帧号/PTS、可见起止、起始区域、路径样本与坐标系、方向/速度、尺度/颜色/亮度变化、末端/结束区域、残留持续、遮挡/画外/截断和证据路径。没有可靠落点保留 null；最后可见点不等于命中位置。首个可见帧不必是真实发射帧。
4. 每个字段/阶段标 OBSERVED、INFERRED 或授权增强 SYNTHETIC，并给置信度。短缺口插值、起始对象关联和接触关联另记推断，不能伪装直接观察；增强需授权依据。源片短于目标时，分开源覆盖与后续适配，不能用循环、冻结或样式迁移冒充缺失源证据。

## 从阶段到轨迹与外观

按参考分解起始 → 运动/传播 → 接触/结束 → 残留/消散；阶段可重叠、缺省或因遮挡未知，不要求每种效果都具备全链。仅起点有光不证明传播已实现，主体运动正确也不证明关键视觉事件已恢复。

- 以可见连续轨迹恢复持续时间与速度，区分持续实体、短尾和瞬时划线；不能套另一个效果的短生命周期。相机运动和主体运动分开，路径位置/方向与亮度包络共用源时间。二维证据不证明三维抛物线或物理模型。
- 起始挂点、路径与结束点分别映射到目标工程，记录源到显示的变换。布局不同时，显示终点适配另记误差/推断，不修改受保护轨迹来掩盖差异，不把最近对象当真实受击者。
- 素材或程序化表达须覆盖参考可见的形状、色彩、尺度、亮芯、拖尾/扩散、持续与退出。按 [素材适配](effects-assets.md) 保留来源；不可借特效层恢复被禁止的参考角色像素。未知浓烟、冲击波或死亡不凭常识补加。
- 保留重叠效果独立生命周期；发射停止不应截断已存在的尾迹或烟尘。跨窗和片尾按源证据检查延续/截断，不为了完整清单凭空延长源片。

## 先区分数据缺失与渲染不可见

沿最终链路查：实际输入/优先级 → 时间窗/输出采样 → 连续路径/阶段 → 挂点与坐标 → 尺寸/亮度/透明度 → 深度/裁剪/覆盖层 → 最终编码。发现代码函数或普通相邻事件，不能证明指定事件已发生。

先渲染受影响片段及边界，与原片、原选定成片作对照。分清“原始最终版”和“上一修复版”的基线标签。再集成全片，检查后半段及结尾；关闭新层核对原图层/状态，防止用特效掩盖损坏。能看见与参考保真分别给结论；多项同时修改只支持组合方案，单项贡献无独立证据则待验证。

## 逐事件验收门槛

每条事件在最终编码 MP4 中提取事前、进行中、阶段切换、退出后的连续帧或片段，保留全幅及局部放大；短事件按实际帧率加密。源片阶段不清晰记 UNKNOWN；确认不适用记 N/A 并附依据，不能强行添加来满足清单。

| 检查 | 通过依据 |
| --- | --- |
| 存在与时间 | 指定事件在对应源/输出帧出现，时间映射可追溯 |
| 位置、方向、尺度、色彩与亮度 | 起始、路径、结束区域及变化与源证据相符，目标画幅可见 |
| 起始阶段（参考可见时） | 起点动作/光/烟等实际组成出现，而非其他对象反馈 |
| 运动或传播（参考存在时） | 连续位移、速度、轨迹与拖尾/烟迹等可见，不能只有起点闪光 |
| 接触或结束（参考存在时） | 时空关系、形状/强度、持续与结束相符，不自动认定伤亡 |
| 残留和消散（参考存在时） | 延续、扩散、衰减与退出连续，不闪断或跨窗消失 |
| 编码后呈现 | 本次实际 MP4 连续证据可见；预览、计数、代码调用、解码成功不能替代 |

每阶段及事件分别记 PASS／PARTIAL／FAIL／UNKNOWN／N/A。参考明确可见但未实现为 FAIL；有所呈现但失真为 PARTIAL；证据或检查不足为 UNKNOWN，不归入 PASS。重要适用阶段均通过且编码已逐事件查看，才给该事件视觉 PASS；程序通过与人工视觉结论分列。记录实际查看范围及视频哈希，未看的事件不因全局 reviewed 标志而通过；重编码后检查记录须重新核对哈希与有效范围。

全片覆盖表保留未检出、未归属、跨窗及后半段失败，不用平均分或总事件数掩盖漏段。独立报告覆盖、连续性、视觉保真及工程检查；素材替换门禁不因特效可见而放宽。
