# V11 镜头尺度修正

已授权镜头局部修正。问题：原 FINAL 为完整容纳红蓝所有纵深而取景过远，角色和战斗过程难读。

本轮不改角色、地形、模型、模拟或事件。CAMERA-A 和 CAMERA-B 使用 FINAL 的逐字节模拟数据副本；只修改相机位置、目标、倍率。维持 1440×2160、60fps、4.2 秒和约 67° 高位俯视。

A：倍率 2.0，取景中心 z=-7，兼顾主要编队；B：倍率 2.55，同中心，聚焦前锋与射击区，允许红后排及部分 U 型底部出画。两版从第一帧到最后一帧相机均固定，无跟随、推拉、切镜或抖动。

曾测试小幅连续平移，开场蓝方出画过多，未用于最终 A/B。初始世界间距较大无法通过真实相机消失；不改站位、不压缩空间、不跳过起跑。选择依据是战斗可读性，不是可见人数最大。

基线哈希：output/camera-revision/protected-baseline.json。新入口 camera.html 与 src/main-camera.js；后者沿用原渲染，只加入可选相机平移参数，最终参数为零。旧 FINAL 和成片保持不变。
