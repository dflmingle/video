# V14 持续个体运动专项

本次授权仅修复冲锋过程中重新趋同的问题，沿用 V13 场景、原素材、初始成员/站位、蓝方部署/射击规则及连续高位镜头，不新增人数或随机坐标偏移。

代码证据：V13 的 `v[j,1]=u['speed']*acc*factor` 在个人起跑完成后变成常量目标速度。不同人确有稍不同的常量和相位，但个人步幅、个人上身姿态也整段固定；仅碰到慢兵/中箭才改变。这是本轮的实际根因。不是方阵中心平移，也不是随机初始站位或固定槽位回拉。此前“同帧姿态不完全相同”的检查无法抓住持续速度趋同。

修改：在稳定成员 ID 上运行个人发力/恢复节奏及受限加速度控制，个人目标速度随自己的发力状态和具体局部阻挡平滑变化；当前速度由逐帧积分与真实占位求解产生。根据实际速度、加速度、转向和个人发力状态平滑调整步幅、步频、上身与摆臂，步态相位积分使用每步实际路径长度/当前步幅，不能用时间乘新的频率造成相位跳变。路线持续指向真实被避让者，通路恢复后再加速，无固定槽位恢复。

受击只作用本人。死亡根坐标固定，近期倒地者也作为局部静态占位参与绕行与速度约束。连续性检查覆盖当前/目标速度、加速度、步幅/步频、相位、邻居相对位置与绕行恢复，不以不同参数数量代替画面。

全段及独立的 20 人局部验证已制作成真实时间 3.0 秒，保守武器包络安全间距下界为 6.4977，大于要求 4。未重复、慢放或延长到双方接触之后。正片与诊断使用同一套真实轨迹和事件；诊断跟踪镜头只在独立视频。最终检查与适用限制见工程根目录 `V14-REVIEW.md`。
