# T1：城墙移至顶部，阴影同步迁移

## 空间结果

固定镜头仍为 `[0,98,65]` 看向 `[0,0,5]`，FOV42、zoom1。中央城墙/城门原生网格在720×1080画面中占y=8.04至92.24像素，移至最上方；外围高塔屋顶自然被上边缘裁切。上一轮保守限制高塔顶部完整入画，此限制未满足用户想要的顶部布局，本轮已纠正。不是缩小模型或移动相机。

城堡建筑组与四个墙脚附件沿原实测墙面法线共同后移17.92世界单位；红军三色整体后移17.60，蓝军原位。全军内部初始相对位置不变。红军位移比测得最大安全值19.10少1.5，保留城堡前额外余量。正面净距由原版4.923763增加到22.523763（+357.45%，即原版4.57倍），明显大于E2的9.847527。

## 阴影根因与修复边界

此前只平移建筑矩阵，遗漏了直接画在 `CastleExterior_Land_C.png` 地面颜色贴图中的城堡阴影，导致旧位置留下深色城墙/双塔影子。原地面材质是Unlit/Texture，这片阴影不是实时光源投射，不能靠移动灯光或碰撞体带走。

保留原始贴图、Unity导出manifest、所有原模型/材质/光照；只对T1候选启用 `sceneLayout.groundTextureOverride`，映射到 `public/native-scenes/layout-derived/topfield/CastleExterior_Land_C-shadow-moved.png`，仅作用于原地面材质 `CastleExterior_Land_Mat`。其他复用地面图集的装饰材质不替换，旧D/E候选不启用。

从原始贴图定位双塔和连接墙影的连通区域，候选副本内清除旧阴影，恢复被遮住的局部地面；提取的阴影明暗层按真实原地面网格UV与世界坐标的仿射关系迁移。城堡世界位移对应UV像素位移约 `[-99.08998,0.19049]`，实测阴影质心位移误差约0.004像素。不是随机画新的阴影，也不是把影子留在原位后再叠加一层。

**原贴图没有无阴影底层**：旧影子下面的地面无法精确取回，因此只在候选派生图集的局部条带，用原无阴影边界做调和插值近似修复。该局部地面颜色/纹理会有变化，不能声称像素级保留了原阴影下面的地形颜色。原资源文件本身未修改；影子位置和无残留以实际渲染图检查，源哈希与派生路径在 `shadow-relocation.json`。

首次尝试按塔影轮廓局部修复出现反向亮色轮廓，实际看图后淘汰，改用局部条带恢复，避免留下塔形亮斑。最终开场实景已核对：原深色墙影及双塔影不再留在旧位置，城堡上沿有与新位置对应的阴影；不是关闭整场阴影。原角色地面阴影仍保留。
