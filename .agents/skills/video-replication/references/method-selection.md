# 按证据选择分析方法

先实际查看开场、中段、结尾、快速变化和遮挡段。记录画幅、镜头运动、对象粒度、可见特征、素材和所需输出，再选算法。下表是选择规则，不是所有项目都要运行的流水线。

| 可见内容 | 首选与可运行工具 | 失败判据与回退 |
| --- | --- | --- |
| 色彩区分明显的图形、UI、顶视群体 | HSV 多范围、排除 HUD、形态学、连通域、PCA/轮廓；`analyze` | 多对象连成块、阴影/特效漏分、阈值轻变就大幅拆合：保留区域候选，查看裁图，分区域配置或 Codex 修正；不推真实人数 |
| 细线图、火柴人、重叠队列 | 颜色/亮度候选、局部边缘、人工圈定群体轮廓；先测闭运算对拓扑的影响 | 组件数远少于可见人物时，组件只能表示线条连通体；不能称实例分割。保留外形/占据场，内部成员用明确合成映射 |
| 有纹理、同视角的背景或刚体 | SIFT+Lowe+RANSAC，`register` 先部分仿射，只有平面透视证据时选 homography；分离拟合/留出点 | 错误内点集中、留出误差大、重复纹理、多层视差：不采用矩阵；改局部注册或人工地标。除中位数外检查 p95 和空间分布，不能只凭多数低误差掩盖局部大错。跨画风匹配尤其不可靠 |
| 小位移、短遮挡的图像结构 | `flow` 前后向 LK；配置门控的匈牙利关联 | 光流跟到背景、跨遮挡跳 ID、形变合并：标 UNKNOWN、人工身份锚点、短窗口重审。候选 ID 不等于物理 ID |
| 移动相机 | 在背景区域做相对注册/光流，检查留出背景点，再将观测转到统一参考平面 | `analyze` **不自动应用相机补偿**。其图像路径不能直接当世界路径；逐时矩阵由现有项目或自建适配器应用后再拟合 |
| 快速运动、抛射物、特效 | 高帧密度、帧差/亮区、边缘线段等候选与逐区连续复核 | 衣服、旗帜、HUD也会高亮；代理面积不是开火次数。射手/命中因果单独绑定，不可靠时 UNKNOWN |
| 真人、复杂遮挡、语义要求高 | 评估环境已提供且适用的目标/分割/姿态模型；在独立标注样本上验收 | 本 Skill 没有打包神经模型/权重。缺模型时不谎称已检测；可用视觉复核和结构化修正完成可观察部分 |
| 真实三维镜头与多层深度 | 已有场景/相机标定、引擎重建；必要时评估额外多视角方法 | 平面 homography 不恢复深度。本 Skill 未实现 SLAM/NeRF/通用 3D 恢复；不以二维公式冒充 |

## 候选到可采用证据

挑选清晰、遮挡、接触、镜头移动和末段样本，保存正反例。说明哪些特征漏检、哪些错误合并；不要只展示通过子集。阈值、核大小和距离门限属于当前分辨率/对象尺度，不跨片照搬。

模板最高分不是语义分类。只有类别可分、负类充足、留出跨帧支持时才考虑采用；失败保留 UNKNOWN，不继续把低门槛结果包装成识别能力。

规则失败时可以由 Codex 直接看图校正框、身份和时刻，将方法记为 CODEX_VISUAL；用户人工修正记 HUMAN_EDIT。二者都不是重新部署了自动检测器。无法肉眼分辨的细节仍 UNKNOWN。

## 渲染选择

按原素材和相机选现有引擎、Canvas/二维精灵、WebGL、Unity 或离线工具。固定视角可用烘焙精灵，需记录方向/阴影限制；真实 3D 保留骨骼与材质，实例化前测动画采样和死亡材质隔离。`render` 仅二维诊断，不能因它支持轮廓就用轮廓占位冒充用户要求的正式角色。
