# V12 冲锋速度与中箭运动专项

本次按用户明确授权，沿用 V11 CAMERA-B 的固定高位俯视镜头和初始站位；不改变人数、兵种、地形或蓝方部署。红方个人目标速度精确乘 1.5，步幅乘 1.15，以累计实际路径驱动动作，正常速度时步频约乘 1.30435。身体前倾由 0.18 调整到 0.22 弧度。

V11 的根坐标已限制前进速度非负，但受击会以长达 0.7 秒的整身踉跄替换跑步，并出现整身后仰和侧摆；普通受击仅剩 12% 速度，后方活人还会因实际占位被迫减速。不能把“坐标未后退”当作视觉问题已解决。

本次将普通受击改为短暂减速和上半身小幅响应，下肢继续由实际移动距离驱动；保留重伤和原生死亡动作。提前预测真实慢兵，持续选定侧向通行路线，保留活人占位约束。命中闪白适当减弱。

加速后重新计算接触前结束时刻，暂以 3.05 秒试算；同时间对照只比较共同时间范围，不冻结或变速。箭矢发射配置不变，飞行终点和命中表须随新轨迹重建；不伪称事件目标表完全相同。

验收：初始成员逐一一致、相机逐帧一致、世界前进方向不反转、死亡根坐标固定、未受击者实际推进、受击者减速及超越、箭矢因果、双方完整武器包络安全间距；最终编码视频抽帧和连续帧人工核查另列，不以程序 PASS 代替冲锋观感。
