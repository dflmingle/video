# 候选 C：首轮箭雨与真实倒地对照（2026-10-30）

基线：`2c821e1` 的 `V22R-fast-A`。交付 C1、C2 的低成本正常速度预览，未制作正式成片。军团初始位置、蓝方 U 型和 7.5 单位集结目标、场景、灯光、固定相机、红军控制器/名义速度/加速度、射程和箭速均保持 A。

**结果：本轮强化真实射击与倒地，安全时间从 A 的 2.317 秒增加至 C1 的 2.650 秒、C2 的 2.667 秒，只增加约 0.33–0.35 秒，未达到增加 1–2 秒或总长 3–4 秒。** 未增加全军减速、后移、世界击退或冻结。C1 更适合作为下一步视觉参考；C2 增加伤亡，却只多获得一帧的安全时间。两版均未通过完整正式验收，原场景穿越、开场裁切与小队松散问题仍存在。

## 首轮实现与真实因果

1. A 已有边集结边准备；本轮没有再次改射程或强行让射手越距射击。早期在射程内的射手数量有限。
2. 原分配将一个目标被一支在飞箭矢占用视为其他射手暂不可射击。本轮仅对未完成首射的射手使用有界目标预约：C1 最多允许同目标两支首射箭预约；C2 参数上限为三支，但本轮实际同时在飞最高仍为两支。不同射手可用真实箭矢连续攻击同一人，不允许未来预约伤害超过当时剩余生命值。
3. 每次分配检查尚未结算箭矢的计划伤害。真实命中前目标必须存活；不会把未命中的伤害提前结算。独立事件重放检查未发现提前死亡、向已死目标结算或首射超额预约。
4. 首轮目标选择在原射程内的暴露目标中考虑原小方阵覆盖；C2 更倾向补射实际已受伤者。没有根据未来死亡预选假目标。
5. 首次合法拉弓前增加逐人稳定错峰，上限 C1 0.09 秒、C2 0.045 秒；完整拉弓时间不缩短。最大一帧 11/14 支，绝非 252 人同帧齐射。
6. 每人首射后恢复原预约、瞄准、拉弓和恢复流程。逐人动作时长、攻击周期参数与 A 完全相同；实际攻击间隔仍可能因目标占用而变化。
7. 单箭伤害仍为原来的 `j % 17 == 0 ? 3 : 1`，生命值仍为 3。没有增加伤害来伪造倒地；死亡增加来自真实多箭命中和目标分配。

代码放在可选 `archers_burst_v22r.py`，原 `archers_v22.py` 仅增加默认不改变行为的扩展点。没有打开 `safeFrontEngagement`，没有使用 V23 或 `motion_volley_v22r.py` 的停止距离控制。

## 受击表现及位移限制

本轮选择通过真实倒地加强受击，不增加根位置反向冲量。C1/C2 的世界反向位移最大均为 **0**，死亡根位置后续移动为 **0**。普通与较重伤者继续走原有逐人伤害减速/恢复流程；致命者在命中时停止主动移动并进入原有倒地动画。

渲染仅把真实命中者原有上身受击脉冲放大为 1.2 / 1.6 倍，持续时间不改，最大局部上身 Z 偏移约 0.156 / 0.208 单位；不是角色根位移、不是模型整体缩放，也不是持续反向推力。未受击者不会获得该脉冲。没有宣称已新增真实世界击退。

两版在视频结束前都只有 2 个死亡动作获得完整的 0.7 秒播放时间，其余处于倒地过程。因此“32/42 次致死命中”不等于所有 32/42 名士兵已在片内完整倒地并静止。独立日志对每次真实伤害和死亡可逐事件追溯。

## 阵型与画面核对结论

实际 MP4 解码截图中箭雨更连续，前排出现真实受击与倒地，U 型轮廓保留；没有上一轮停止距离控制产生的长条漏斗。C1 相对克制，C2 局部空洞、伤亡和橙黄前后衔接的拥挤略多。

但原版小队轮廓本就明显松散，本轮终点最大小队宽度倍率 C1=2.597、C2=2.604；中位倍率约 2.056 / 2.060。没有把“不新增长条漏斗”写成“清晰 3×3 与凝聚力全部通过”。

两版固定相机每帧位置、四元数、FOV、zoom、投影矩阵均一致。蓝方根位置全程 252/252 可见；红方开场最低为 291/972，后期全体根位置入画。原后军开场出画、原行军路径穿过城墙仍存在，故两版都不通过完整场景空间与无穿模验收。环境资源、材质和灯光未动。

视觉核对范围：实际浏览器 C1 中后段截图；实际编码 C2 全时间抽帧与首次释放 F83–F85、首次命中 F101–F103、结束 F157–F159 连续帧；C1 实际编码末帧；三栏对照实际编码 F138。没有可用的连续正常速度视频视觉输入，因此不声称已正常速度观看完整片或排除所有短时抖动。两个正常速度 MP4 可直接播放。

## 为什么不能再多拍 1–2 秒

C1 首个被拒绝状态为 2.6667 秒，保守下界 3.9563；C2 为 2.6833 秒，保守下界 4.0054，低于保留的 `4.0+0.05` 缓冲门槛。安全检测、包络半径和缓冲没有放宽。

最后接受状态的最近前排分别为受过轻伤的黄军 R0887、R0893，生命值均剩 2，仍以约 14.76 / 16.44 单位/秒推进。真实伤亡替换了一部分最前端成员，却没有消除持续高速冲锋的后续队列；继续增加倒地不能自动创造空间。

按原名义高速 21.75 单位/秒，计算从当前安全截止继续前进需要消耗的路径长度：

| 目标结束时间 | C1 后续高速路径预算 | C2 后续高速路径预算 |
|---|---:|---:|
| 3.0 秒 | 7.61 | 7.25 |
| 3.5 秒 | 18.49 | 18.13 |
| 4.0 秒 | 29.36 | 29.00 |

这是假定保持该高速时的**新增真实行进空间量级**，不是已经验证可通过某个最小整体平移获得的距离，也不是新的安全轨迹。实际最小所需净空间须结合局部方向、蓝军运动和射程重新求解。后移会延迟进入射程；当前布局又受城墙和固定镜头约束，本轮没有自行挪兵来满足此表。

**结论：单靠本轮首轮强化与真实倒地，不足以解决战场空间问题。停止在实际安全时间，不增加反向击退、冻结或大规模参数扫描。**
