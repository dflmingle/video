# C1 冻结前段与续战预览

本轮以 `7c20b43` 的 C1 为源。交付范围是低成本预览，不是正式 1440×2160 成片。用户最新近战要求覆盖旧版“红蓝武器包络表面净距 4.0 即结束”规则；身体碰撞继续约束。

## 已冻结内容

原版状态 F0–F159（0–2.65 秒）直接复制。轨迹、红蓝控制、累计路程、步态周期、受击时间六项权威数组要求逐位一致，原始放箭、命中、死亡事件与已发箭起终点保持不变。渲染前段使用原事件视图，避免未来攻击改变过去瞄准方向。原视频为159帧 F0–F158，F159仅存在于原模拟。

原 C1 和新前段 720×1080、60fps 的159帧已做像素差检查：每帧同样12个静态环境像素出现差异，最大通道差6/255，平均通道差0.000046725/255。差异原样保留，没有施加像素容差，不宣称文件哈希或所有像素完全一致。数据/事件检查与像素检查分开。

## 后段规则与因果

红军按附近存活蓝兵选择目标；仅局部接敌者进入接近与攻击，原生 attack 动作约0.466667秒，在55%相位首次跨越时（60fps采样约57.14%）核查距离和朝向。挥砍期间目标身份锁定，原目标被别人杀死则挥空，下一次攻击重新准备，不把旧相位传给新目标。蓝军3生命，每次合法红军近战伤害1；并未指定胜负。

未被近身压迫的射手沿用检查点中的个人攻击周期。近身者中断射击并短距离避让，死亡射手不再发箭。飞行中箭不被取消。截止前箭路冻结；后续箭释放时预测实际目标运动，落点之后不回填。命中按该帧实际积分后的目标位置检查，失败记MISS。

所有兵与尸体用地面圆盘占位，半径0.29，首选中心间距0.615；固定尸体不被弹簧拖动。联合速度投影后各人仅积分一次，同时检查整段扫掠最小距离。独立安全检查保留至少0.02身体余量，即中心距0.60。不是完整动画网格的逐三角面碰撞，武器挥动重叠也不等同身体root穿透。

尸体阻挡时局部导航到多个存活蓝兵的攻击圈，未使用单个U型中心。胜负后按个人参数连续减速，保留最后倒地，不单帧冻结全军。

## 失败诊断保留

- 首次实现发现18次后段箭伤害在移动前判定，实际impact帧目标已偏离箭端；已改为实际积分后结算并重新模拟，旧预览目录 `output/v22r-melee/failed-arrow-order-preview` 仅供诊断。
- 首次实现存在挥砍中换靶继承相位、胜负后全军单帧归零，已修正。
- 试图强制恢复大于当前接触间距会在尸体包围的区域构成无解约束，已撤回。求解首选个人间距与实际身体直径分开，不用无解约束制造瞬移。

## 独立遗留问题

原 C1 已存在开场部分军团出画和城墙穿越，本轮未移动军团或场景。后段战斗扩展到画面下沿、近战区域很密，须以候选预览评审；不擅自变焦、移动机位或重排队伍修饰。近战后的三色方阵因实际接敌、伤亡和尸体阻挡而局部混战，不能据事件计数声称阵型视觉已获用户认可。
