# 返工案例与防复发检查

下列是可迁移的失误链及检查方法，不代表某个项目已经得到用户最终认可。项目实际数量、时间点、路径与截图留在项目记录。遇到对应症状时读相关项，不需要每次完整展开所有专项。

## 1. 人数不少，战场仍空；区域统计通过，合围仍不可读

- **误判**：把源表“战术单位”解释为单兵，把多个方向有敌人解释为合围。
- **失败修改**：增加箭头、字幕、攻击特效和外围点数，沿用错误粒度与静态布阵。
- **新增问题**：表面热闹，但军队纵深不足，分兵/包围/突破的因果消失。
- **根因**：数量模型和剧情空间关系未梳理；代理统计脱离观众实际看到的过程。
- **有效方法**：先核实编队、成员与实际个体，再画双方目标与阶段路径；用代表性密度灰盒打通翼侧合拢、开口产生和实际穿越。
- **防复发**：看目标画幅的连续片段，核对局部间距、纵深、持续补入、接战与转折；同时检查每个“成员”是否真有需求规定的状态。
- **适用边界**：数量、群体与战术关系重要的镜头；不强制单角色演示拥有战斗模拟。

## 2. 队首很快，后队拖慢或卡死

- **误判**：少数人在动就说明整队通畅，单一编队中心能表达所有人的运动。
- **失败修改**：提高全局速度、同时移动所有槽位、冻结拥堵后列。
- **新增问题**：前后速度断层、突然加速、同步停顿、换位整片平移。
- **根因**：整体路线、队列目标、局部避让与通道容量不一致；局部成员无法独立解决真实路径。
- **有效方法**：按需要拆战术小组，保持整体意图；逐人处理路径、转向、占位和汇入，以世界空间累计路程控制速度。
- **防复发**：分别跟踪队首、中段、后列和指定对象，覆盖进入窄道、持续通过、离开与整队；不能只看平均速度。
- **适用边界**：群体运动和换位；不要求所有演出升级成战略 AI。

## 3. 加了避让，仍穿岸/穿人；改尺寸后能力失效

- **误判**：端点在粗略区域就安全，画面尺寸和碰撞半径可以隐式代表兵种。
- **失败修改**：局部推开角色后不重验地形；用半径阈值判定冲撞能力。
- **新增问题**：修复互穿却被挤出岸边；调整美术比例后技能悄悄不触发。
- **根因**：约束分步各自成立，最终状态没有联合验证；能力耦合外观数据。
- **有效方法**：显示和可行区域同源，最终位移检查扫掠、占位及边界，必要时传播移动拒绝；能力显式由角色职责与状态定义。
- **防复发**：测弯道、窄口、边缘和连续推挤；换尺度后检查动作能力、有效目标和战果。初始化中修正位置时，同步更新依赖该位置的路径游标等状态。
- **适用边界**：真实运动约束；装饰副本必须明确其不参与碰撞的限制。

## 4. 源码已改，报告或视频仍是旧效果

- **误判**：文件修改、检查 PASS 或页面刷新等于当前代码全部生效。
- **失败修改**：沿用旧预计算快照、旧图集或旧构建，反复查看同一份截图。
- **新增问题**：数值报告与浏览器不一致，调整不断叠加却无法判断真实效果。
- **根因**：构建/缓存依赖没有完整失效，证据没有绑定产物版本。
- **有效方法**：覆盖代码、配置、几何、素材、种子等输入的依赖标识；顺序完成生成、构建、加载、检查与录制。
- **防复发**：核对浏览器实际入口、构建/缓存哈希与新截图、导出；不能仅看某个文件时间戳或旧 PASS。
- **适用边界**：有构建、烘焙、预计算或缓存的项目；无须给简单静态片段造复杂发布系统。

## 5. 本地文件正确，浏览器加载失败；预览好，成片差

- **误判**：文件后缀决定响应体编码；预览或封面能证明成片正常。
- **失败修改**：对浏览器已解压的响应再次解压；按墙钟不断截图；只查视频规格。
- **新增问题**：开发/预览环境表现不同、帧时间漂移、黑帧、重复帧、裁切与音效错位。
- **根因**：忽略 HTTP 实际传输和统一输出时间，未检查编码产物。
- **有效方法**：核对响应头与实际响应体、加载完成信号；用统一时间采样，实际解码并查看导出连续片段及声音。
- **防复发**：分别确认页面加载、真实交互/顺播、录制状态与最终文件；精确描述查看范围，抽帧不称全片逐帧，音轨存在不称听验。
- **适用边界**：涉及压缩资源和视频导出时；不无故强制离线渲染或新录制框架。
