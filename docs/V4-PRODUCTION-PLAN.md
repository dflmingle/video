# 第一段 V4：A/B/C 对照制作

用户确认 V3 编组更清楚但冲锋气势不够。本次保留三军前后归属、各军 3×3 小队、蓝方七队 U 型、原 FBX/武器和远程命中因果；允许组内连续合理初始差异，不再坚持复制网格。V3 与其他旧工程均保护，V4 独立端口 5244。共享资产/依赖仅只读使用，不运行会写共享资源的准备脚本。

根因对象是红军在最终画面中的冲锋表现：旧版相同小队外形、弱前沿差异、宽空白及正对称正交构图，使实际推进看起来像平移。不是人数不足；先改组织模型、动作和投影。

先制作三个同为 5.2 秒、包含部署→加速→射箭→命中→末段高速切镜的短预览：A 保持红军 972/蓝军252，优化前沿、个体连续差异、斜俯视透视；B 同人数，增加小队纵深差与疏密层次；仅在真实角色动作、编组及性能检查可用后测试 C，在 B 基础适度增加约 17% 红军，不改变 3×3 层级或混兵。

前锋有稳定先锋身份、更积极起跑/加速度和持续速度；前中后排差异与小队推进节奏同时存在，但不是每帧噪声。小队边缘与局部纵深有连续变化，宏观编组不跨军。骨骼保持真实素材，累计路程驱动跑步、前倾和武器动作，检查支撑残余而不只提平移速度。

相机先测试固定的偏轴斜俯视透视镜头，让近端前锋相对放大、纵深压缩留白，保证所有主要编组和 U 型可见；不震动、不运动模糊，不用摄像机替代真实位移。根据真实截图调整取景。

箭矢挂接实际射手手部姿态，绑定目标及死亡；末段保留尚在飞行的箭并区分未结算事件。无伤亡与战斗两种路径均检查武器/身体包络间距，结尾仍高速推进，不设置集体刹车。

预览输出实际编码 MP4、同阶段并排、局部动作连续帧、速度/密度/前沿与渲染耗时。分别评价气势、组织可读性、跑步、密度与渲染，选实际画面最优者输出完整高分辨率成片与重建入口。制作者评价和用户最终认可分开；不把多人数、事件计数、视频编码成功当作视觉 PASS。
