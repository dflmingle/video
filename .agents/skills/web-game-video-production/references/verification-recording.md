# 浏览器验收与录制交付

## 版本与基线

修改前保存当前运行画面与必要状态。修改后依次完成构建、转换/缓存生成、服务启动和页面加载，再运行依赖检查。核对代码与素材、缓存、前端构建、截图及导出的版本；时间戳只作最低限度证据，有构建 ID 或哈希时一起记录。

现有服务先核对归属与版本，开发服务和预览服务可能加载不同产物。不要连续刷新仍在编译/生成的进程，不覆盖待处理录制请求，不将任务已接收当成已完成。只读的独立检查可并行，共享状态操作顺序执行。

## 检查必须能抓住原问题

每个检查问：“如果用户说的问题依然存在，这个检查还会通过吗？”答案为是就补直接证据。

| 验收对象 | 有效证据 | 无法替代的代理指标 |
| --- | --- | --- |
| 关卡/剧情 | 各阶段的触发、动作、反应、结果与衔接连续可见 | 总时长正确、事件计数正确、结尾卡片出现 |
| 密集军队 | 目标画幅的局部间距、纵深、连续补入与实际个体状态 | 源表总人数、渲染实例数量 |
| 合围与突破 | 翼侧移动和封堵、受压方反应、开口形成、实际穿越与后果 | 多方向计数、箭头、字幕、镜头外伤亡 |
| 指定对象移动 | 指定队首及后列在目标阶段的连续位置/朝向 | 其他部队在动、走路动画播放 |
| 碰撞与边界 | 真实占位、通道合法性及扫掠/接触；复杂拐角实测 | 有 Collider、坐标位于粗略区域 |
| 特效与命中 | 真实目标、起点、组成、先后、持续/退出逐项比对 | 粒子存在、颜色相近、命中次数非零 |
| 可玩交互 | 实际输入影响状态、反馈与约定的结果/循环 | 按钮能点、固定影片自动播放 |
| 重播/跳转 | 与同版本顺播一致，包括死亡、效果、UI和结束态 | 时间标签到了、角色大致在附近 |
| 当前版本 | 当前浏览器/构建及依赖产物对应 | 历史 PASS、旧截图、未失效缓存 |

代码断言用于实际规则、占位或状态不变量，不能重复实现后当需求证明。局部低风险改动无需新造测试框架；复用已有检查并覆盖直接回归风险。

## 亲自看真实运行画面

用实际浏览器在目标分辨率、像素比、画幅和相机下查看，不能只看离线模型预览。先确认页面已加载新代码及资源，检查控制台、网络与加载失败。

- 基线和修改后使用可对应的镜头/阶段。检查视觉重心、两侧均衡、轮廓、留白、遮挡、文字、缩放、环境尺度与 UI 安全区。安全区来自实际渠道要求或模板，不编造统一数值。
- 动态看连续帧或录像，覆盖进入、持续、退出、变速和状态切换。关键细节放大，不能只看缩略拼图；检查停顿、瞬移、穿模、转向跳变和旁观者同步反馈。
- 对“部队太少/太空”等问题，实际看兵潮轮廓与空间分布，不只提高一个人数参数。对“流程不清楚”重新核对因果，不用亮光、箭头或字幕掩盖缺失阶段。
- 原片比对记录对应的源时间与本片阶段，合理统一裁切/比例；逐项核对所采纳动作，不要求无关镜头像素一致。
- 主动修复看到的明显问题，再生成新的证据。助手审美检查与用户最终认可分开记录。

没有浏览器自动化工具时，可使用已有可用浏览器和受支持截图方式。仅 HTTP 可访问和静态检查通过不能声称已视觉验收；实际无法查看时说明未核范围，不伪造证据。

## 录制方式与时间基准

优先项目已有录制流程，按目标选择实时捕获、浏览器帧序列或可确定求值的离线渲染。不为简单录制安装无关框架。

- 录制规格按用户需求；未知但不阻塞时写明确的预览假设。固定相机、画幅、字体和 UI；关闭调试叠层、辅助线及非成片控件，保留需求中的模拟游戏界面。
- 贴图、图集、字体、音频、着色器及模拟缓存全部就绪后再录。开始帧不能包含初始化黑屏、缺图或无设计依据的跳位。
- 区分墙钟、模拟时间、动画时间和输出帧时间。离线第 `n` 帧按统一约定的 `n / fps` 求值，说明首帧/末帧与持续时间；不能边截图边依赖墙钟继续推进。
- 粒子、UI、随机、音频事件和状态锁存也服从输出时间。缺失逐时刻求值能力时先验证替代录制，不假定放慢浏览器就自动同步。
- 录制模式的状态与正常浏览器顺播比对，防止只在离线模式移动。真实交互需要录制其输入/结果，预计算演出不能代替可玩性验收。
- 工具传图走路径或资源引用；帧序列与日志分批处理，避免大量 Base64 或一次返回整片帧。载荷超限先缩小范围，不原样重试。

## 检查实际编码文件

重要视觉事件执行 [编码后逐事件核对](effects-rendering.md#编码后逐事件核对)。全局 reviewed 或粒子计数不能批量批准未人工查看的事件；将覆盖、最终可见性和参考保真分列，原始成片与上一修复版使用不同标签。

编码完成后检查文件可播放、画幅/分辨率、帧率、时长及需要的音轨，再实际解码查看开头、关键动作、转折、转场和结尾。检查裁切、文字、压缩后角色细节、黑帧、重复/丢帧、音画同步与结束截断。

全局时间或状态变更后查看完整流程；局部修改查看受影响片段及关键结尾。按异常持续时间选择连续采样和步进检查，必要时逐帧；不能将低频抽帧说成排除了所有短暂异常。

记录查看方法和范围：完整播放、哪些连续片段、什么采样间隔、哪些逐帧范围。导出了每一帧但只看拼图不叫逐帧核对。音轨存在/波形有能量不代表听验通过；无法实际听验就说明限制。

## 交付与完成判定

交付可编辑工程、浏览器入口、可玩预览、视频或其组合，并明确版本。用户要求启动时实际启动服务，检查页面和入口，给可点击访问地址与必要交互说明；本地地址不宣称是公开部署。

说明启动/构建命令、必要资源转换与缓存生成、当前有效文档和成片路径。需要复制给别人运行时，纳入所需依赖与素材；不能把只在当前机器缓存存在时能跑的页面称完整工程。

报告对应需求的具体改变、当前有效证据和未完成项。明确 2D/2.5D/3D、实时/预计算、脚本/自主、可玩/演示边界，以及影响交付的真实限制。工程检查、助手视觉核对、用户认可分别记录；未修完失败项或未检查导出时不宣布对应任务完成。
