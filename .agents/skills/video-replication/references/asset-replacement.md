# 素材来源契约与独立验收

仅在用户要求使用指定新素材替换参考对象时应用；适用于角色、产品、车辆、建筑、图形等，不限媒介、题材或引擎。

## 先恢复契约

记录用户指定文件、存在/可加载状态、哈希、职责、适配产物与转换步骤，以及需保留的比例、轮廓、颜色、材质、形态和辨识特征。绑定锚点、单位、朝向、动画语义、根运动和遮挡；区分原生动画与程序重定向。转换记录明确是否有裁切、透明处理、补绘、改色或几何简化；不能默默改变关键外观。

恢复已有实现时寻找最后一个真正使用指定素材的渲染版本，分别审查其素材正确性与空间运动质量。空间或运动失败不是放弃正确素材架构的理由。旧版若仅部分对象/时段使用素材，必须记录混用范围，不能称全片替换通过。

## 分离分析与最终绘制

允许的数据流：参考媒体→观测/分割/光流→对象与成员证据→位置/朝向/可见性/轨迹/事件→指定素材实例→动画/渲染→编码与对照。

原片对象轮廓、像素和边缘可以参与分析，但不能作为替换对象的最终形状、纹理、矢量路径或逐帧描绘。参考截图可显示在清楚标注的验证面板。若参考背景依法在授权范围内使用，须与对象层隔离，检测原对象残留，不能借背景层混入原对象。特效和背景的重用不能绕过对象替换契约。

实际检查最终绘制调用和资源依赖，不仅看配置名称：定位覆盖分支、缓存精灵、材质/贴图、逐帧图层和最终 framebuffer。每个可见实例应可追溯到素材哈希与当前状态写入者。未知身份、合成槽位和遮挡补全分账，不能把描线几何命名为“成员”绕过检查。

## 三项预验收

1. **静态替换**：在清晰参考时刻按观测位置和朝向渲染指定素材，保留其辨识特征；检查锚点、比例、镜像与遮挡。观察截图并保存实例→素材映射。
2. **短时运动**：约一秒连续区间，稳定显示 ID 驱动指定素材；检查位置连续、转向、缩放、进出/遮挡、动画和镜头。身份不确定标 INFERRED/UNKNOWN，不能称自动恢复真实身份。
3. **来源检查**：验证实际加载文件与哈希，记录实际绘制调用/实例来源；拒绝参考对象的轮廓、边缘或帧作为角色输入。提供适用的对象层开/关对照及像素差分，证明对象来自独立图层。同时用网络/依赖/调用检查，不能只凭画面相似作结论。

缺素材或不可加载先报告，替换 FAIL/BLOCKED，不用原对象临摹替代。只有上述证据证明新素材进入最终输出，才推进依赖它的完整制作；无需重复请求已有授权。

## 独立评分与报告

优先级：素材来源与外观→对象/成员位置、分布、轨迹与可见性→事件、镜头、特效→像素或感知相似度。分别报告 PASS/PARTIAL/FAIL/UNKNOWN/BLOCKED；素材替换 PASS 不自动批准复刻保真，工程 PASS 不自动批准任一视觉项。用户要求替换时，即使原片描线相似度高，也必须判替换 FAIL，不得以 PARTIAL 淡化路线错误。

交付来源契约、实际加载与绘制记录、静态图、短时视频、参考对照、回归与剩余差异。通用规则只记录来源隔离与验收方法；具体素材路径、角色、阵型、阈值和时段留项目记录。
